# Product requirements

`TripAlogue-PRD.docx` is a Word export of the TripAlogue product requirements document. The living copy is the
Claude doc [TripAlogue — Product Requirements Document](https://claude.ai/artifact/WHfvL3ZwsVx3Nu6VbiMJKm); this
file is regenerated and committed whenever that document changes, so the repo always carries the current PRD.
