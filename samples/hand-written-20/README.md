# Sample: Portugal in Ten Days (hand-written, 20 items)

The Phase 0 exit fixture: a project file written by hand, with 20 media items
across 4 chapters, that must play end to end in the player shell.

Media is synthetic and generated by `npm run sample` (ffmpeg). What each item exercises:

| Item | Exercises |
| --- | --- |
| m01–m02, m06–m07, m11–m12, m16–m17 | Default fit placement for landscape and portrait stills |
| m03, m08, m13, m18 | Panorama stills letterboxed by fit; m03 and m18 run 6 s |
| m04 | Custom placement rectangle (left half of the frame) |
| m08 | No cue in the file: cue-profile defaults apply and it plays last in its chapter (a validation warning, by design) |
| m09 | Fill placement with 1 s fades |
| m05, m10 | Full video clips; m10 is a portrait clip, recorded before m09 but ordered by its cue |
| m14 | Excluded (`included: false`): never plays |
| m15 | 20 s clip played in full (no out-point: videos play to their end by default) |
| m19 | Cut entrance and exit, no fades |
| m20 | In-point at 2 s, played at 2x speed (10 s of media in 5 s) |

Porto's title card is 4 s instead of the default 3 s.
